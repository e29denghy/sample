# Fable 5.1 发布，AGI 要来了？先别急

![几条模型路线正在汇合，但终点仍在雾里](https://denghy.cn/images/articles/agi-is-coming/00-cover.png)

今天凌晨看到 Fable 5.1 的发布帖，我第一反应不是“AGI 来了”，而是：模型升级的速度，已经快到我们来不及形成稳定印象。

几周前还觉得很强的能力，转眼成了对照组。更麻烦的是，闭源模型在跑，国产开源模型也没停。大家像是突然拐进了同一条路：不再只比聊天，而是比谁能把一件事做久、做完、做得更便宜。

## Fable 5.1 真正吓人的，不是分数

Claude 官方给出的数字很亮眼：Terminal-Bench-Science 从 Fable 5 的 24.7% 提到 52.6%，Terminal-Bench 4.0 从 42.0% 提到 55.8%，计算机操作也从 72.9% 升到 77.9%。官方还说，它在展示的七项评测里都领先 Opus 5 和 GPT-5.6 Sol。

先别急着把这张表当结论。它是厂商自己选的评测、自己的运行配置，能证明“进步很大”，不能证明“全面碾压”。

我更在意另一句话：Fable 5.1 更擅长复杂、长时间运行的任务。模型开始从一次答对，转向连续工作。科学研究、写代码、操作电脑和知识工作，正在被塞进同一个 Agent 循环里。

这比某个榜单第一更接近 AGI 的味道。

## Astra，就是大家说的“ChatGPT 6”吗？

如果按产品代际看，基本可以这么理解：Astra 是 OpenAI 正在准备发布的新一代前沿模型，也就是大家口中的“ChatGPT 6”这一代。准确地说，官方这次使用的名字就是 Astra，没有称它 GPT-6，也没给出正式发布日期。当前公开旗舰仍是 GPT-5.6，网上流传的 9 月窗口只能当参考。

OpenAI 9 月 1 日公开的信息已经足够重磅。官方称 Astra 将“很快”开放，并把它列为首个达到 Critical 网络安全能力阈值的模型：在合适工具和权限下，它能发现未知漏洞、组合利用链，在没有人逐步指导的情况下完成攻击任务。OpenAI 也因此推迟了部分训练和发布，先补安全措施。

所以，纠结它最后叫 Astra 还是 GPT-6，反而没那么重要。真正的分水岭，很可能不是“更会回答”，而是“能否长时间行动，以及行动时是否守边界”。

## 国产开源模型已经挤进同一条赛道

过去一个多月，国产模型的节奏很密。

Kimi K3 开放了 2.8T MoE 权重，把原生多模态、编程、知识工作和 Agent 训练放进同一个模型。GLM-5.3 随后开放权重，重点就是 Agent 编程和网络安全。DeepSeek V4 Pro 在 8 月转为正式版本，继续把长上下文和 Agent 能力往前推。

最有意思的是 Qwen3.8-Flash。它不只是一个新版本，官方直接把它称为 Qwen4 架构的早期预览：125B 参数，每个 token 只激活 6B，原生 262K 上下文，可扩展到 1M，而且同步开放权重。

闭源前沿模型在争更高的能力上限，国产开源模型在把能力、成本和可部署性同时往前推。两边不是同一种打法，却越来越像在解同一道题：怎样让模型真正接手工作。

## 所以，AGI 要来了吗？

我的判断是：已经能看见轮廓，但还不能把钥匙交出去。

会连续做十小时任务，不等于十小时都知道自己在做什么；能在评测里操作电脑，不等于遇到陌生环境还能稳定收手；能发现漏洞，也不等于能对现实后果负责。

现在的模型最缺的，不一定是又多几个百分点，而是三件朴素的事：知道自己什么时候不确定，出错后能真正回到正确轨道，面对没见过的环境仍然守住目标和边界。

如果把 AGI 理解成一个突然亮灯的时刻，我不觉得它会在某场发布会上出现。如果把它理解成“越来越多工作开始可以交给通用 Agent”，那它已经在路上，而且比大多数人预想得快。

只是今天更准确的说法仍然是：我们正在进入 AGI 的前夜，不是第二天早晨。
